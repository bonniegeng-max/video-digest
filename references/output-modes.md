# Output Modes

Use the language of the user's current request. Translate headings naturally.

## Quick

Include:

- title, channel, duration, source link, and transcript type;
- a two- or three-sentence summary;
- five timestamped takeaways;
- “best for” and “skip if” guidance;
- one important caveat.

## Deep

Include:

- the main question, thesis, and conclusion;
- a timestamped structure;
- an argument map for each material claim;
- the video's reasoning and cited evidence;
- limitations or counterpoints;
- notable quotations and useful follow-up questions.

Label source statements as `Video statement` and interpretations as `Author opinion`.

## Research

Add a claim-verification table after the Deep notes:

| Timestamp | Material claim | Result | Evidence | Scope |
|---|---|---|---|---|
| 00:00 | | Supported / Partly supported / Contradicted / Not verified | Primary source | Date, population, version, or jurisdiction |

Verify only claims that materially affect the video's conclusion.

## Batch Quick

| Video | Thesis | Three useful timestamps | Evidence quality | Novelty | Recommendation |
|---|---|---|---|---|---|
| | | | High / Medium / Low | High / Medium / Low | Deep now / Save / Skip |

Use the same criteria for every video.
